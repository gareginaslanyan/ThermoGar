# Тексты лицензий баз данных

Здесь лежат полные тексты лицензий, под которыми распространяются
термодинамические, мобильностные и физические базы MatCalc, поставляемые
с ThermoGar, и производные от них файлы.

| Файл | Лицензия | Что покрывает |
|---|---|---|
| `ODbL-1.0.txt` | Open Data Commons Open Database License v1.0 | права на саму базу как на набор данных |
| `DbCL-1.0.txt` | Open Data Commons Database Contents License v1.0 | права на отдельные записи внутри базы |

Тексты взяты дословно, без правок, с сайта Open Data Commons 11.09.2026:

* `ODbL-1.0.txt` — <https://opendatacommons.org/licenses/odbl/odbl-10.txt>,
  SHA-256 `607680718977f6f6c9607972afd98f208573f19251315ed1362a8589b51beaf5`;
* `DbCL-1.0.txt` — <https://opendatacommons.org/licenses/dbcl/dbcl-10.txt>,
  SHA-256 `3cbfa990f26df856c6a7d3fff3d1f236e3b0165b1e8257ca0d00f15758754f81`.

Каталог входит в поставку обязательным: ODbL требует, чтобы копия лицензии
сопровождала базу, а ThermoGar работает офлайн — ссылка на сайт текст
лицензии пользователю не заменяет.

Правообладатель баз и источники файлов — `SOURCES.txt`; разбор соблюдения
условий — `docs/DATABASES.md`, разделы 2 и 5.
