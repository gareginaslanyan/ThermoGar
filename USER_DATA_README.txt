THERMOGAR / user_data

Папка создаётся автоматически при первом сохранении пользовательских данных.

alloys.json       — пользовательские марки и составы
alloys.json.bak   — резервная копия предыдущей версии библиотеки
projects/         — локальные файлы проектов .thermogar.json
history.jsonl     — история с цепочкой контрольных сумм
history_*.bak     — резервные копии после очистки истории
logs/errors.jsonl — технические отчёты ошибок ThermoGar

Не удаляйте user_data при обновлении ThermoGar. Для переноса на другой
компьютер копируйте всю папку ThermoGar либо отдельно user_data.
