# Stage 14 — основания архитектуры свойств

Stage 14 построен по двум исходным отчётам из `docs/evidence`.

## Принятые принципы

1. Химический и равновесный фазовый состав не определяют автоматически
   инженерную прочность, твёрдость, пластичность, ползучесть или усталость.
2. Для упругих свойств допустима первая оценка через объёмные доли фаз и
   Voigt–Reuss–Hill, если intrinsic-свойства фаз заданы отдельно.
3. Hall–Petch, Taylor и Orowan требуют явных параметров микроструктуры и
   alloy-specific коэффициентов.
4. Ни одно значение без источника не превращается в встроенный дефолт.
5. Неопределённость не придумывается.
6. ML-модель может появиться только после отдельного назначения, экзамена,
   замороженного состояния, контрольной суммы и проверки области применимости.
7. Отсутствие модели является штатным статусом, а не поводом считать другим
   движком «по умолчанию».

## Реализация Stage 14

- физические формулы отделены от будущих ML-моделей;
- локальная библиотека фаз хранит происхождение и источник;
- по умолчанию вклады упрочнения не складываются;
- автоматические UTS, твёрдость и удлинение не показываются;
- учебный пример помечен как демонстрационный.
