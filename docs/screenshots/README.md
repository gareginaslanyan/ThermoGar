# Снимки экрана

Сделаны волной 11B на живом приложении, запущенном из исходников (не из установленной копии),
на контрольном составе ХН62М(Sc)-ВИ при 400 °C, никелевая база `mc_ni` 2.036.

Состав (массовые %, основа Ni): `C=0.005, SI=0.10, MN=0.50, S=0.020, CR=23.5, MO=13.0,
NB=0.06, AL=0.25, TI=0.10, FE=0.50`.

## Снимки волны 11K

Сделаны 11.09.2026 на живом приложении, поднятом из исходников рабочего дерева
`C:\Users\gareg\Desktop\ThermoGar-w11k` (Streamlit, headless, `PYTHONHASHSEED=0`,
`THERMOGAR_STATE_ROOT` во временный каталог сессии — установленная копия и
`%LOCALAPPDATA%\ThermoGar` не затрагивались). Воспроизводится скриптом
`tools/make_wave11k_screens.py`.

| Файл | Что на нём |
|---|---|
| `08-estimated-density-warning.png` | предупреждение об оценочной плотности: фазы `DELTA`, `MNS_Q`, `MU_PHASE`, `NI2CR` не имеют модели в физической базе и оценены по правилу смеси. Никелевая база, контрольный состав ХН62М(Sc)-ВИ, 400 °C, ручной набор фаз |
| `09-steel-passport-installed.png` | панель «Паспорт базы» для стали **в установленной конфигурации**: каталога `databases/diagnostic` нет, и панель читает отпечаток эталона — «эталонная база не поставляется, сверка по отпечатку», SHA-256 и признаки помечены «(из отпечатка)» |

Снимок 08 закрывает пункт `11K-3.1`, снимок 09 — `11K-3.2`.

**Про набор фаз на снимке 08.** Взят ручной набор `FCC_A1`, `NI2CR`, `MNS_Q`,
`P_PHASE`, `MU_PHASE`, `DELTA`, а не автоматический. На автоматическом наборе
никелевой базы расчёт плотности вообще не доходит до физической базы: pycalphad
валит `Workspace` с `ValueError` ещё до расчёта равновесия. Дефект найден этой
волной и заведён в бэклог, к плотности отношения не имеет.

**Про снимок 09.** Каталог `databases/diagnostic` на время съёмки
переименовывается скриптом и возвращается на место в `finally`; ничего не
удаляется. Ключ `--keep-diagnostic` отключает это поведение.

**Пункт `11K-3.3` — сообщение об исключении `C15_LAVES`** — снимать не
понадобилось: он уже снят волной 11E, файлы `04-c15-exclusion-in-result-fast.png`
и `05-c15-exclusion-in-result-all.png` выше, оба с живого приложения.
