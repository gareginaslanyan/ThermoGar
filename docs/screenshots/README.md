# Снимки экрана

Сделаны волной 11B на живом приложении, запущенном из исходников (не из установленной копии),
на контрольном составе ХН62М(Sc)-ВИ при 400 °C, никелевая база `mc_ni` 2.036.

Состав (массовые %, основа Ni): `C=0.005, SI=0.10, MN=0.50, S=0.020, CR=23.5, MO=13.0,
NB=0.06, AL=0.25, TI=0.10, FE=0.50`.

| Файл | Что на нём |
|---|---|
| `01-fast-preset-warning.png` | предупреждение о фазах, не вошедших в быстрый набор |
| `01b-fast-preset-block.png` | блок «Управление фазами» целиком: переключатель набора и то же предупреждение |
| `02-excluded-phases.png` | список исключённых фаз с причиной (`BCC_B2`), режим «все фазы базы» |
| `03-phases-400c.png` | устойчивые фазы при 400 °C в быстром наборе: `NI2CR` присутствует, доля 80,3 % |

Снимки используются в `USER_GUIDE_THERMOGAR.md` и в `docs/HN62M_STUDY.md`.

Третье сообщение волны 10 — пометка оценочной плотности — здесь не снималось. Оно срабатывает
на том же пути, который проходит пункт A2 волны 11A (плотность сплава на исправленном коде),
и снимок приложит поток A.
