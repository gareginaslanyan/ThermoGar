# physical_data.pdb в ThermoGar

## Источник и назначение

В комплект включён исходный файл `physical_data_v103.pdb`. В его заголовке
указана версия 1.03 от 19.06.2009. Параметр `DP` обозначен как плотность.

SHA-256 файла в комплекте:

`4cf81c992b57263c50b370ea47eb0d5bb4f622cf23c18479bab54267762f20bd`

## Что читает ThermoGar

- 101 активную функцию;
- 121 активный параметр `DP`;
- температурные выражения;
- подрешёточные эндмемберы;
- бинарные взаимодействия в форме Редлиха–Кистера;
- один известный десятичный разделитель `120,331`, нормализуемый при чтении.

Прямые модели найдены для 13 фаз:

`ALN`, `BCC_A2`, `CEMENTITE`, `CU_S`, `DIAMOND_A4`, `FCC_A1`, `HCP_A3`,
`LAVES_PHASE`, `LIQUID`, `M23C6`, `M3C2`, `M6C`, `M7C3`.

## Три статуса результата

1. **Прямая модель** — имя фазы есть в PDB.
2. **Оценка по связанной фазе** — используется физическая модель структурно
   связанной/разупорядоченной фазы; это не выдаётся за прямое значение.
3. **Нет данных** — число не рассчитывается.

## Пересчёт долей

Для каждой фазы ThermoGar использует её равновесный состав, среднюю молярную
массу и плотность. Затем рассчитывает массу и объём. Полная объёмная доля и
плотность всего сплава выводятся только при покрытии всех равновесных фаз.

## Ограничения

- база старая и не покрывает большинство специальных фаз современных Ni-, Fe-
  и Al-TDB;
- точность параметров определяется источниками и оценками самой PDB;
- наследование плотности ordered/disordered-фаз является инженерной оценкой;
- ThermoGar не рассчитывает по этой базе параметры решётки, упругость или
  теплопроводность;
- зелёный внутренний тест означает корректность парсинга, а не экспериментальную
  аттестацию всех составов.
