## 7. Предложение (шаг 3 22-А2) — только текст, код не менялся

**7.1. Остановка BL-35 на стали — оставить как защиту, причину убирать шагом по времени.**

* **Защиту оставить.** Во всех 49 остановках состояние на шаге остановки негодно: в выделениях
  1,11–1,44 C сплава, а с сеткой (0,5; 10) — доля 100 % и до 3,2·10⁴ C сплава. Показывать его нельзя.
* **Настройками kawin 0.5.0 причину не убрать.** Единственная настройка без остановки на всех зёрнах —
  `minComposition = 1e-8`: на 3,6 с доля 4,4085–4,4087 %, R 8,10–8,23 нм у зёрен 0–2. Но перелёты
  остаются — 8–9 растворений ~30 % выделений за шаг за 3,6 с, и итог несёт их след. Это страховка: C
  матрицы не доходит до 0, где термодинамика не определена. Остальные четыре предела строже в
  10 раз остановку не убирают, `maxVolumeChange` ломает начало расчёта (п. 6 в).
* **«Иначе» — ограничить рост шага.** В kawin 0.5.0 рост шага ограничен только при `dt == dtMax`
  (`KWNEuler.py:347–348`), в остальных случаях предел может отпустить шаг в десятки раз. Набросок
  «шаг ≤ 2× предыдущего» дал на 3,6 с: ни скачков, ни растворений за шаг, ни остановок на зёрнах 0–2;
  доля 4,4095 %, R 9,517–9,519 нм у всех трёх; 1447–1528 строк, 43–44 с — быстрее умолчания
  (59–81 с). ⟨2д-набросок⟩ Место — `run_precipitation`, подкласс модели рядом с
  `_MatrixCompositionStop`, kawin не править:

  ```python
  class _StepCappedPrecipitateModel(PrecipitateModel):
      """22-А2: шаг по времени — не больше двух предыдущих (BL-43)."""

      DT_GROWTH_CAP = 2.0

      def getDt(self, dXdt):
          dt = super().getDt(dXdt)
          n = int(self.data.n)
          if n > 0:
              dt = min(dt, self.DT_GROWTH_CAP * float(self.data.time[n] - self.data.time[n - 1]))
          return dt
  ```

  Плюс `setConstraints(minComposition=1e-8)` — страховка от неопределённой термодинамики, если
  перелёт всё же случится.
* **Признаку — отличать, по одному числу: невязке баланса до шага остановки.** Перелёт шага —
  `max |x0 − [(1−f)·x + f_conc]| ≤ 1e-12·x0` на всех шагах до остановки: учёт точен, недопустимое
  состояние родилось внутри одного шага. Разрыв баланса — если больше: утечка копилась по шагам (не
  наблюдалась ни разу). Порог — по числам ⟨все остановки⟩. Пересыщение перед остановкой и рост шага —
  только пояснение: на 3,6 с в 49 остановках C на предыдущем шаге — 1,28–1,71 растворимости, шаг
  растёт ×6–42; у остановки умолчания на 0,05 ч C прошёл растворимость шагом раньше (1,55 → 0,94 x_eq
  при росте шага ×2,9). Набросок:

  ```python
  def _stop_kind(data, n, element_index):
      """«перелёт» или «разрыв» для остановки на шаге n (22-А2)."""
      x0 = data.composition[0, element_index]
      fv = data.volFrac[:n].sum(axis=1)
      fconc = data.fconc[:n].sum(axis=1)[:, element_index]
      x = data.composition[:n, element_index]
      residual = np.max(np.abs(x0 - ((1 - fv) * x + fconc))) / x0
      return "перелёт" if residual <= 1e-12 else "разрыв"
  ```

  С `minComposition > 0` условие BL-35 по зажатому составу слепнет: на 0,05 ч с `1e-8` принимались
  состояния с долей выше предела по углероду (п. 6 д). Поэтому условие остановки должно смотреть на
  баланс до зажима — `f_conc ≥ x0` по добавке (то же, что «сырой» состав ≤ 0), а не на `x ≤ 0`.
