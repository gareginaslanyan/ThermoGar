## 5. Что уже видно по сделанным прогонам (дополнительного счёта нет)

`scripts/shag_ostanovki.py` → `logs/shag1_shag_ostanovki.txt`, трассы стадий RK4 —
`data/*_trace.csv.gz`.

1. **Баланс C до шага остановки точен**: `max |x0 − [(1−f)·x + f_conc]|` по всем принятым шагам до
   остановки — 0 … 1,7·10⁻¹⁸. kawin считает состав матрицы из баланса масс, утечки нет.
2. К 0,67 с C матрицы выходит на плато **3,8–3,9·10⁻⁵** при доле M23C6 4,408 %; равновесный состав
   феррита на конноде kawin (`xEqAlpha`) — **2,751·10⁻⁵**, x_C/x_eq = 1,37–1,43. Это укрупнение:
   Rcrit ≈ R̄ ≈ 7–8 нм, зарождения нет.
3. На плато шаг по времени периодически прыгает **×11–13** (например 0,0058 → 0,0758 с,
   ограничитель — `computeDTfromRcrit`). Такой шаг RK4 «пинает» систему:
   * вниз — растворение за шаг (доля 4,408 → 3,041 %, C матрицы 3,8·10⁻⁵ → 2,96·10⁻³), затем
     восстановление; у зерна 0 так было на 0,8; 0,94; 1,02; 1,46 с;
   * вверх — стадия RK4 полного шага уводит C в минус (−1,4·10⁻⁴), kawin зажимает его в 0
     (`minComposition = 0`), и из этого состояния следующая стадия получает ложную положительную
     движущую силу (≈1,5·10⁹ Дж/м³ при C = 0) и вспышку зарождения. Принятый шаг: N ×105–134
     (1,6·10²² → 2,1·10²⁴ м⁻³), доля 4,41 → 6,1–6,4 %, в выделениях **138–144 % всего C сплава**,
     «сырой» C = −0,41…−0,47·x0. Тут и срабатывает BL-35.
4. Предварительный ответ на BL-43: **численный перелёт** (слишком крупный шаг явной схемы на
   квазиравновесном плато, через растворимость ~2,8·10⁻⁵ сразу в отрицательный C, усиленный зажимом
   в 0 внутри стадии RK4), а не разрыв баланса масс. Момент — случайный, потому что направление
   очередного «пинка» решает округление. Проверять это полагалось шагами 2–3; они не начаты.
