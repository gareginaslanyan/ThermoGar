## Итог

1. **BL-43: численный перелёт через растворимость, а не разрыв баланса масс.** Во всех 50
   остановках баланс C в kawin до шага остановки выполняется до 1,9·10⁻¹⁶·x0; в 49 остановках на 3,6 с
   C матрицы на предыдущем шаге — 1,28–1,71 равновесной растворимости (2,75·10⁻⁵; pycalphad и
   `xEqAlpha` kawin совпадают), а шаг по времени на шаге остановки вырастает в 6–42 раза. Полный шаг
   RK4 уводит C матрицы в минус, kawin зажимает его в 0, а при C = 0 движущая сила M23C6 **не определена**:
   решатель pycalphad не сходится, kawin этого не проверяет, и выходит то +1,5·10⁹, то −4,4·10⁹ Дж/м³ —
   в зависимости от стартовой точки решателя. С плюсом — ложное безбарьерное зарождение
   (Rcrit 0,39 нм, J ≈ 10²⁵ м⁻³с⁻¹), в выделениях 1,002–1,44 всего C сплава, остановка BL-35. С
   минусом — растворение ~30 % выделений за один шаг, и расчёт идёт дальше.
2. **Момент остановки — случайная величина.** Ячейка приложения на Linux останавливается на 10 зёрнах
   из 10: 0,765 с (зёрна 4–7, 9), 1,981 с (0), 2,431 с (1, 3), 3,109 с (2, 8); на Windows при зерне 0 —
   1,418 с.
3. **Настройки kawin 0.5.0.** Остановку на всех зёрнах убирает только `minComposition = 1e-8`, но
   перелёты остаются (8–9 растворений за шаг за 3,6 с). `maxVolumeChange = 1e-4` — ложный успех:
   второй шаг 2,27 с перепрыгивает зарождение. `maxRcritChange`, `maxDissolution`, `maxDtFrac` строже в
   10 раз не помогают. Отказа от шага с повтором в kawin нет. Корень — рост шага ничем не ограничен:
   набросок «шаг ≤ 2× предыдущего» (не настройка kawin, обёртка в скрипте) убирает и скачки шага, и
   перелёты, и остановку на всех зёрнах; итог между зёрнами совпадает до 4 знаков, счёт быстрее.
4. **0,05 ч (умолчание раздела на стали) результата не даёт.** Второй шаг — 22,7 с: предел по объёму
   меньше dtMax принимается как есть, и шаг перепрыгивает зарождение; выделение идёт на 104–106 с вместо
   ~0,75 с, а на 110,7 с — остановка BL-35, после 14,7 мин счёта. `minComposition = 1e-8` не спасает: тот
   же шаг, затем 9–11 тысяч шагов с углеродом в выделениях больше, чем в сплаве (до 1,017·x0), — молча,
   до предела 30 мин на 118–123 с модели. С ограничением роста шага умолчание доходит до 180 с на зёрнах 0–2 за 12 мин,
   доля 4,4116 %, R 18,87 нм у всех зёрен одинаково.
5. **Предложение** (п. 7): остановку BL-35 оставить как защиту; причину убирать ограничением роста
   шага, `minComposition = 1e-8` — страховка, но только вместе с условием остановки по балансу до
   зажима; перелёт от разрыва отличать по невязке баланса до шага остановки;
   эталоны «2391 строка» и «1,418 с» заменить исходом и долей; текст остановки для стали неверен —

## 7. Предложение (шаг 3 22-А2) — только текст, код не менялся

**7.1. Остановка BL-35 на стали — оставить как защиту, причину убирать шагом по времени.**

* **Защиту оставить.** Во всех 50 остановках состояние на шаге остановки негодно: в выделениях
  1,002–1,44 C сплава, а с сеткой (0,5; 10) — доля 100 % и до 3,2·10⁴ C сплава. Показывать его нельзя.
* **Настройками kawin 0.5.0 причину не убрать.** Единственная настройка без остановки на всех зёрнах —
  `minComposition = 1e-8`: на 3,6 с доля 4,4085–4,4087 %, R 8,10–8,23 нм у зёрен 0–2. Но перелёты
  остаются — 8–9 растворений ~30 % выделений за шаг за 3,6 с, и итог несёт их след. Это страховка
  (C матрицы не доходит до 0, где термодинамика не определена) — и то лишь вместе с условием остановки
  по балансу до зажима: на 0,05 ч с ней 9–11 тысяч шагов подряд принимались состояния с C в
  выделениях больше, чем в сплаве (п. 6 д). Остальные четыре предела строже в 10 раз остановку не
  убирают, `maxVolumeChange` ломает начало расчёта (п. 6 в).
* **«Иначе» — ограничить рост шага.** В kawin 0.5.0 рост шага ограничен только при `dt == dtMax`
  (`KWNEuler.py:347–348`), в остальных случаях предел может отпустить шаг в десятки раз. Набросок
  «шаг ≤ 2× предыдущего» дал на 3,6 с: ни скачков, ни растворений за шаг, ни остановок на зёрнах 0–2;
  доля 4,4095 %, R 9,517–9,519 нм у всех трёх; 1447–1528 строк, 43–44 с — быстрее умолчания
  (59–81 с). На 0,05 ч (80 классов) — 180 с на зёрнах 0–2 за 11,7–12,0 мин, доля 4,4116 %,
  R 18,866–18,868 нм, ни растворений за шаг, ни негодных состояний. Место — `run_precipitation`, подкласс модели рядом с
  `_MatrixCompositionStop`, kawin не править:

  ```python
  class _StepCappedPrecipitateModel(PrecipitateModel):
      """22-А2: шаг по времени — не больше двух предыдущих (BL-43)."""

      DT_GROWTH_CAP = 2.0

      def getDt(self, dXdt):
          dt = super().getDt(dXdt)
          n = int(self.data.n)
          if n > 0:
              dt = min(dt, self.DT_GROWTH_CAP * float(self.data.time[n] - self.data.time[n - 1]))
          return dt
  ```

  Плюс `setConstraints(minComposition=1e-8)` — страховка от неопределённой термодинамики, если
  перелёт всё же случится.
* **Признаку — отличать, по одному числу: невязке баланса до шага остановки.** Перелёт шага —
  `max |x0 − [(1−f)·x + f_conc]| ≤ 1e-12·x0` на всех шагах до остановки: учёт точен, недопустимое
  состояние родилось внутри одного шага. Разрыв баланса — если больше: утечка копилась по шагам (не
  наблюдалась ни разу). Порог — по числам 50 остановок: до шага ≤ 1,9·10⁻¹⁶·x0, на шаге — избыток C
  в выделениях от 1,8·10⁻³·x0 до 3,2·10⁴·x0; 10⁻¹² лежит в 4 порядках над шумом и в 9 — под наименьшим
  нарушением (`logs/a2_s3_vse_ostanovki.txt`). Пересыщение перед остановкой и рост шага —
  только пояснение: на 3,6 с в 49 остановках C на предыдущем шаге — 1,28–1,71 растворимости, шаг
  растёт ×6–42; у остановки умолчания на 0,05 ч C прошёл растворимость шагом раньше (1,55 → 0,94 x_eq
  при росте шага ×2,9). Набросок:

  ```python
  def _stop_kind(data, n, element_index):
      """«перелёт» или «разрыв» для остановки на шаге n (22-А2)."""
      x0 = data.composition[0, element_index]
      fv = data.volFrac[:n].sum(axis=1)
      fconc = data.fconc[:n].sum(axis=1)[:, element_index]
      x = data.composition[:n, element_index]
      residual = np.max(np.abs(x0 - ((1 - fv) * x + fconc))) / x0
      return "перелёт" if residual <= 1e-12 else "разрыв"
  ```

  С `minComposition > 0` условие BL-35 по зажатому составу слепнет: на 0,05 ч с `1e-8` принимались
  состояния с долей выше предела по углероду (п. 6 д). Поэтому условие остановки должно смотреть на
  баланс до зажима — `f_conc ≥ x0` по добавке (то же, что «сырой» состав ≤ 0), а не на `x ≤ 0`.
