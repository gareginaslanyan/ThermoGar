## 11M-2. Плотность хрома: значение подставлено

`enabled: true`, `status: "filled"`, `expression` и `source` заполнены.
Байты `physical_data_v103.pdb` не тронуты.

### Что записано

Замкнутая форма — ровно та, что дана в задании:

```
ρ_Cr(T) = 7181,91 · exp( −[F(T) − F(298,15)] )
F(T)    = a·T + b/2·T² + c/3·T³ − d/T
a = 6.21989e-5 K⁻¹   b = -7.13041e-8 K⁻²   c = 4.36412e-11 K⁻³   d = -2.883384 K
DTCRBCC = ρ_Cr(T) − D0BCC_CR,   D0BCC_CR = 7200 кг/м³ (из базы, строка 54)
```

Опорная точка взята базы, а не из статьи: `D0BCC_CR + DTCRBCC(298,15 K)` даёт
ровно **7181,9137 кг/м³**, что со справочной плотностью хрома 7190 и со
значением 7200 по параметру решётки 2,8839 Å согласуется, а `M/V₀` по таблице 1
статьи дало бы 7385 кг/м³ — немагнитный объём опорной точкой служить не может.
Из оценки взят только полином расширения.

### Экспоненту пришлось раскрыть рядом, и это дешевле подгонки полиномом

Грамматика поля `expression` — та же, что в `.pdb`: разбор идёт через
`ast.parse` с белым списком узлов, в котором есть только `+ - * / **`, имя `T`,
числа и имена `FUNCTION`. Вызовов функций нет, значит нет и `exp`.

**Скобки, однако, поддержаны** (`ast.BinOp` вложенный), поэтому вместо подгонки
полиномом к кривой записано разложение самой экспоненты в ряд Тейлора:

```
DTCRBCC = 7181.91*(1 - X + X**(+2)/2 - X**(+3)/6 + X**(+4)/24) - 7200.0
X       = a*T + (b/2)*T**(+2) + (c/3)*T**(+3) - d*T**(-1) - F(298.15)
```

На 298,15…2130 K показатель `|X| ≤ 0,066`, поэтому отброшенный остаток ряда
ниже `1e-8` относительных. Длина выражения — 587 символов.

**Максимальное отклонение подгонки от точной формы** (задание просит привести
явно):

| Окно | Максимум отклонения |
|---|---|
| 298,15…2130 K (до плавления хрома) | **3,0·10⁻⁴ кг/м³** = 4,5·10⁻⁶ % |
| 298,15…1373,15 K (рабочее окно программы) | **2,2·10⁻⁶ кг/м³** |

В точке 298,15 K выражение даёт **ровно** 7181,91 кг/м³ (равенство
с плавающей точкой, не приближённое). На 298,15…2130 K монотонно убывает.

Для сравнения, обычная подгонка полиномом по методу наименьших квадратов на том
же окне даёт максимум отклонения 8,4 кг/м³ (степень 3), 5,1 (степень 4) и
2,4 (степень 5), причём степени 5 и выше при экстраполяции за 2130 K
разворачиваются вверх и дают положительную бессмысленную плотность вместо
отрицательной, которую сторож приложения ловит. Ряд Тейлора лучше на четыре
порядка и от этого недостатка свободен.
