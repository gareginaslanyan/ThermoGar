## 2. Остановка 1 и решение мастера (продолжение)

Остановка: «как в приложении» противоречит «C15_LAVES в наборе в обоих» —
`FE_EXCLUDED_PHASES = {"C15_LAVES"}`, приложение снимает её в обоих режимах набора
(`compatible_phases_for_components`), и в быстром наборе `fe` её нет. Без C15_LAVES в
наборе файлы с патчем и без дают одинаковые числа. Второе: `main` на `ac31640`, а не на
`2a41e88`.

Решения мастера:
- Fe: полный набор = цепочка приложения БЕЗ шага effective_release_phases (C15_LAVES в наборе);
  быстрый = пресет fe плюс C15_LAVES; оба варианта — на обоих файлах (def6c686… с патчем и
  99b5cd56… без); плюс на каждую стальную марку одна опорная строка «как в приложении» (с патчем,
  без C15_LAVES, полный набор, 1e-6, pdens 50), столбец metod = «ThermoGar-app». В отчёте и в
  16A_sravnenie.md прямо сказать: в приложении C15_LAVES исключена всегда, варианты с ней — вне
  штатного пути, нужны для ответа «Лилит» о цене патча;
- столбец «наше» в 16A_sravnenie.md для стали — с C15_LAVES, с патчем; опорная строка приложения

- реестр не трогать (он в другом дереве не нужен — ветка та же, но правит его задача слияния);
  «Ошибку мастера (16-А)» — противоречие «как в приложении» против «C15 в наборе» — запишет

## 3. Остановка 2 и решение

Остановка: у `scheil.simulate_equilibrium_solidification` нет параметра доли жидкости.
Солидус там — первая T, при которой LIQUID нет в `eq.Phase`; порог задаёт решатель pycalphad
(снимает фазу при NP < 1e-9, при нарушении правила фаз — < 1e-4). `binary_search_tol` —
точность по температуре в °C, а не порог; `SOLID_PRESENCE_FLOOR` действует только на ликвидус.

Решение (выбран рекомендованный вариант): ликвидус — `equilibrium_liquidus_c` с
`SOLID_PRESENCE_FLOOR` = порог. Солидус в строках 1e-4 — `bisect_transition_temperature`
приложения по NP(LIQUID) ≤ порога через `equilibrium_solid_fraction_at` (доля жидкости =
1 − доля твёрдого), вилка по траектории scheil, точность 0,1 °C. Та же бисекция при 1e-6 —
отдельным столбцом `T_sol_bisekciya_K`, чтобы отделить критерий scheil от порога. Столбец
`kriterij_solidusa` в CSV.
