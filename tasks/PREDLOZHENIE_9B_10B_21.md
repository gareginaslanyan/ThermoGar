### Порядок свёртки и строки `st.columns`

Ранг 1 — меняют реже всего, сворачивать первым. Ранг 1 — вид графика и настройки выгрузки. Ранг 2 — окна поиска, геометрия, параметры модели. Ранг 3 — шаги сетки и начальные значения, которые пользователь заметно чаще подбирает под задачу. Мастер сворачивает по рангу, пока кнопка не встанет на первый экран; положение кнопки замеряет 21-И.

Строки `st.columns` экономят высоту, только если свёрнута вся строка:
- S02 «От / До / Шаг» (`app/ThermoGar_app.py:7712`), S03 «от / до / шаг» (`:8052`), S13 «Температура от / до / Шаг» (`:1883`): диапазон — вопрос расчёта, поэтому шаг остаётся в строке. Если свернуть только шаг, высота не меняется.

### Как увидеть, что в свёрнутом блоке значение не по умолчанию

Вариант А (рекомендуется). Над основной кнопкой — подпись `st.caption` «Не по умолчанию: {подписи полей через запятую}.». Подпись появляется, только если хоть одно свёрнутое поле отличается от умолчания своей базы. Новых слов нет: «по умолчанию» стоит на экране (`app/ThermoGar_app.py:9721`, `app/thermogar_diffusion.py:1429`, `app/thermogar_precipitation.py:1601`), подписи полей — их собственные. Подпись не зависит от состояния блока и видна рядом с кнопкой.

Вариант Б. К названию блока добавить « · не по умолчанию», например «Точность и критерии · не по умолчанию». Новых слов нет. Риск: Streamlit различает блоки по аргументам. Смена названия может создать блок заново и закрыть его, пока пользователь вводит значение. Это нужно проверить в тяжёлом потоке до выбора варианта.

Вариант В. Открывать блок (`expanded=True`), если в нём есть значение не по умолчанию. Риск тот же, что у варианта Б.

Для сравнения нужны умолчания по базам. Они уже лежат в словарях кода: `DATABASE_DEFINITIONS`, `*_DEFAULTS` в `app/ThermoGar_app.py`, `DEFAULTS` в `app/thermogar_diffusion.py` и `app/thermogar_precipitation.py`.

#### Причины по коду для неосмысленных умолчаний

1. **S02 и S13, fe — 3 точки.** `DATABASE_DEFINITIONS["fe"]`: «default_t_min» 400, «default_t_max» 1200, «default_t_step» 400 (`app/ThermoGar_app.py:351–353`). Сетка — `np.arange(t_min, t_max + 0.5·step, step)` (`:7798–7805`, для S13 `:1905–1912`) → 400, 800, 1200 °C. Те же поля передаются в S13 (`:11827–11829`). Вывод «малоинформативный» сделан по коду: кадра этого умолчания нет.
2. **S03, fe — одна фаза.** У «Изменяемый элемент» нет умолчания по базе: `st.selectbox` без `index` (`app/ThermoGar_app.py:8034–8038`) берёт первый элемент отсортированного списка без основы. У fe это Al, у al — Cr, у ni — Al. «Постоянные добавки» пусты (`:8045–8050`). Поэтому у стали по умолчанию считается двойная система Fe–Al на 0–20 мас.% (`:8055–8069`) шагом 10 (`:8074`) — 3 точки одной фазы BCC_B2 (кадр 05).
3. **S05, ni — сечение почти пустое.** `ISOPLETH_DEFAULTS["ni"]`: Al 0–10 ат.%, Cr=15, Co=10, 900–1500 °C (`app/ThermoGar_app.py:544–553`). В этом окне почти только γ: на кадре 16 видны линии ликвидуса и солидуса около 1400 °C и начало границы γ′ у 10 ат.% Al и 900 °C. Комментарий `:540–542`: шаги подобраны под время расчёта 1–2 минуты.
4. **S14, шаг 2 — отказ.** `property_library_prefill` отдаёт пустые E, ν, происхождение, источник и температуру отсчёта для фаз, которых нет в локальной библиотеке (`app/thermogar_verified_properties.py:907–917`). `_validate_vrh_rows` отказывает при любом пустом из них (`:953–955`).
5. **S15 — отказ.** «Источник и область применимости входов» по умолчанию пусто (`app/ThermoGar_app.py:2402–2405`) и уходит как `None` (`:2461`). Проверка отказывает: USER_INPUT_REQUIRED, «Укажите источник и область применимости всех коэффициентов.» (`app/thermogar_verified_properties.py:1074–1081`). Если заполнить источник, следом отказывает не поставленная галочка «Подтверждаю…» (`app/ThermoGar_app.py:2406–2409` → `app/thermogar_verified_properties.py:1085–1086`; своего русского текста у этого отказа нет, `_fail` без текста для экрана — `:162–163`). Даже с обоими полями все механизмы по умолчанию выключены (`app/ThermoGar_app.py:2426`, `:2442`, `:2448`, `:2451`, `:2458`), а правило — «Не суммировать» (`:2416–2424`). Результат по умолчанию после заполнения обязательных полей — только базовое сопротивление 0 МПа, то есть малоинформативный (нужен прогон, чтобы увидеть точный вид таблицы).
6. **S17, ni — выбрана одна фаза.** `DEFAULTS["ni"]["homogenization_phases"]` = FCC_A1, BCC_A2 (`app/thermogar_diffusion.py:103`). Умолчание собирается как пересечение с фазами, у которых есть подвижность для всех элементов пары (`:1659–1661`). Для Ni–Cr–Al BCC_A2 в это пересечение не входит, остаётся одна FCC_A1. Запасной выбор «первые две фазы» (`:1662–1663`) срабатывает только при пустом пересечении, поэтому не срабатывает. Кнопка активна, так как фаз в списке не меньше двух (`:1648`, `:1714`). После нажатия — отказ «Для многофазной гомогенизации выберите минимум две фазы.» (`:1717–1718`; кадр 27). Что вторая фаза с подвижностью у этой пары — NIAL, следует из теста `tools/test_ui_g.py:74–75`, который на этой паре проходит.
7. **S17, al — кнопка выключена.** В `mc_al 2.037` подвижность есть только у FCC_A1 (`app/thermogar_diffusion.py:1645–1657`, `tools/ui_matrix_G.md:45–48`). Это свойство базы, а не умолчание: причина показана до нажатия. Кандидата нет.
8. **S11, fe — корня нет на широком окне** (вероятно; нужен прогон). Окно по умолчанию 300–1700 °C (`app/ThermoGar_app.py:434–435`). Сохранённый результат: на 900–1300 K разность энергий немонотонна, корень не находится (`tools/backend_reference.md:193–197`). Подпись экрана сама советует узкое окно (`app/ThermoGar_app.py:11603–11611`).

**Нужен источник:**
- базовое внутреннее сопротивление σ₀ — для Ni-сплавов (γ-матрица), Al-сплавов (Al–Cu), сталей (Fe–Cr–C, феррит);
- k_y (Hall–Petch) — для тех же трёх групп;
- размер зерна — данные конкретного образца (металлография), не константа базы;
- множитель Тейлора M — для ГЦК (Ni, Al) и ОЦК (Fe) поликристалла;
- α (Taylor) — для ГЦК и ОЦК матрицы;
- модуль сдвига G матрицы — Ni, Al, Fe, с температурой отсчёта (или E и ν фаз с источником для пути через Hill);
- вектор Бюргерса b — Ni (ГЦК), Al (ГЦК), Fe (ОЦК);
- плотность дислокаций — данные состояния образца;
- коэффициент Пуассона ν матрицы — Ni, Al, Fe (или путь через Hill);
- радиус частиц и расстояние между ними — данные микроструктуры (радиус может прийти из «Выделений», расстояние — нет);
- твёрдорастворный вклад — модель и коэффициенты для Ni (Cr, Co, Mo, Al), Al (Cu, Mg), Fe (C, Cr, Ni).

Без этих источников кандидата с числами нет. Пресет «учебные значения» из теста не предлагаю: он подставил бы числа без источника и поставил бы подтверждение за пользователя, а поле и галочка обязательны именно для явного решения пользователя.
