### Как собрана

Скрипты лежат в `results/wave21_g/scripts/`:

- `extract_candidates.py` — все строковые литералы `app/*.py` с кириллицей (части f-строк склеены, докстроки исключены), в которых есть латинское слово вне списка «не находка» или слово из словаря программиста. Имена фаз берутся из строк `PHASE` самих баз в `databases/converted` (только чтение). Вторая выборка — латиница без кириллицы прямо в подписях вызовов Streamlit.
- `latin_only_constants.py` — латинские строки из двух и более слов вне `raise`, ключей словарей и служебных аргументов.
- `annotate_candidates.py` — к каждому кандидату объемлющая функция и вид места (`raise`, вызов `st.*`, присваивание).
- `screen_corpus.py` — корпус строк экрана без недостижимых функций; по нему проверен столбец «новое / уже есть».
- `build_opis.py` — строки описи. Решение «выходит ли текст на экран» принято вручную по коду для каждого кандидата. Столбец «сегодня» берётся из кода по адресу; длинные markdown-блоки даны дословным фрагментом с находкой.

## Отступления и замечания

1. **Одна строка описи на несколько мест.** Однородные тексты одной функции сведены в одну строку, адреса перечислены через запятую. Например, десять проверок файла проекта в `thermogar_workspace.py` получили одно предложение «Структура файла не совпадает с ожидаемой.». Причина — один текст на экране и один ответ владельца. Число мест в итоге посчитано по адресам.
2. **Вид места шире списка задания.** Кроме видов из задания используются «столбец» для строк и значений таблиц и «подпись (значение поля по умолчанию)» для `DECLARED_SCENARIO_INPUT_NOT_MATERIAL_QUALIFICATION`. Где в одной строке две формы, вид записан через «/». Причина — в списке задания нет вида для строки таблицы и для значения поля.
3. **Строки «без изменений» (6).** Латиница и ключи, которые по W-1 остаются, описаны с предложением «без изменений» и объяснением. В единый список они не идут. Это:
   - имена авторов, учреждения и лицензий: TU Wien, ODbL-1.0, DbCL-1.0; атрибуцию требует лицензия;
   - «T = const» — обозначение из словаря материаловеда;
   - `ni`, `al`, `fe` — значения, которые пользователь сам вписывает в шаблон пакетного расчёта;
   - «кодировка — UTF-8»: пользователь сам сохраняет CSV в этой кодировке;
   - текст «пустого решения» (`app/thermogar_stage14.py:97–102`). Его утвердил владелец в 15-Н2, но в нём остаются «вернул» и «решатель» — это на решение владельца.
4. **ZIP.** Этого формата нет в списке исключений задания. Он описан как формат выгрузки, предложение — «Скачать полный архив, ZIP», по образцу решённого владельцем «Скачать состояние модели, NPZ». Строка стоит в части 2.
5. **MatCalc и имена программ в «Проверке установки».** MatCalc описан как имя программы, по аналогии с Kawin: предложено только убрать слово «нативном». Таблица «Окружение» (`app/thermogar_stage14.py:871–889`) перечисляет программы и версии: Python, Streamlit, NumPy, SciPy, pandas, matplotlib, xarray, openpyxl. Имена программ отдельными строками не описаны. Описаны заголовок «Окружение» и строка «Корень проекта».
6. **Столбец «Оригинал из базы (англ.)»** в «Справочнике фаз» (`app/ThermoGar_app.py:5731`) не описан. Это дословная английская цитата описания фазы из файла базы, и подпись столбца сама это называет.
7. **Предложения описи, опирающиеся на новые слова 21-В, стоят в части 1 отдельными строками**, со ссылкой на исходную строку 21-В. Это, например, «загруженные настройки» (как А7), «записи не менялись после сохранения» (А23), «история расчётов повреждена», «изменена вручную» (А24), «исходных данных диффузии» (Г1). Их «да» зависит от «да» на исходную строку.
8. **Ошибки языка искались не сплошным чтением.** Проверены тексты, прочитанные при разборе кандидатов, и блоки вокруг них. Все русские строки экрана (около 12 тыс. литералов в корпусе) целиком не вычитывались. Найдено 3 ошибки, перечислены выше.
9. **Строка 67 CSV 21-В совпадает с А21** (`app/thermogar_workspace.py:1684`). В части 2 она дана одной строкой А21 с пометкой «= строка 67 CSV 21-В».
10. **Вне задания замечено: дробная запятая на экране.** Это нарушение решения владельца от 24.09.2026:
    - `app/ThermoGar_app.py:11911` — «2000 K (1726,85 °C)»;
