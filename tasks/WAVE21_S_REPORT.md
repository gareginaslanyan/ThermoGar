В браузере (`static/static/js/DataFrame.*.js`) пустая ячейка рисуется текстом `placeholder ?? "None"` серым; для галочек, графиков и прогресса не рисуется. Данные не меняются.

- Форма чисел без `format` (`static/static/js/formatNumber.*.js`): 4 знака после точки, для 0 < |x| < 1e-4 — по порядку числа; хвостовые нули убираются; без разделителя тысяч. По этому правилу в б/в собран текст (`shown_number` в `proba/app.py`); сверка — кадр `kadry/kalibrovka_chisel_svet.png`.

## Шаг 4 — отступления

- Проба: вариант а2 (`style.format(na_rep="—")`) добавлен сверх задания — для сверки замера мастера на ноутбуке. Для редактора а2 = а: Styler в `st.data_editor` действует только на нередактируемые столбцы (`streamlit/elements/widgets/data_editor.py:813`).
- Проба: вариант г снят в двух видах (г0 `placeholder=""`, г1 `placeholder="—"`), потому что средство Streamlit одно, а выбор пусто / «—» — за владельцем.
- Съёмка: в Chromium Streamlit 1.62 сохраняет файл через `showSaveFilePicker`; чтобы Playwright поймал скачивание, в страницу пробы до загрузки вставлено `delete window.showSaveFilePicker` (`proba/scripts/kadry.py`, `NO_PICKER`). Streamlit тогда скачивает обычной ссылкой; содержимое файла от этого не зависит.
- Съёмка: столбцы в сетке рисуются на canvas; щелчки по заголовку и ячейке — по координатам, найденным по разделителям в строке заголовка чернового кадра.
