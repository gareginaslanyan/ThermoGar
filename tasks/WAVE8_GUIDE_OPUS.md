# Задача 8 — иллюстрированное руководство: по каждой вкладке пример «куда нажимать»

Worktree `C:\Users\gareg\Desktop\ThermoGar-w8`, ветка `wave8-illustrated-guide`. Python — основной venv по абсолютному пути.
Код приложения (`app\`) не менять. Результат — только `docs\guide\` + один сводный файл.

## Цель
Для каждой из 7 вкладок — короткий сценарий «сделай так»: 4–8 шагов, на каждом шаге скриншот с подсветкой
элемента (рамка + номер шага), под ним одна-две фразы: что ввести, что нажать, что увидишь. Плюс общий раздел
«Первый запуск» (ярлык, боковая панель: база, основа, единицы, состав, температура). Язык — русский, тон — как в
`docs\FEATURES.md`. Читатель — материаловед, не программист.

## Как делать скриншоты — воспроизводимо, не руками
1. `pip install playwright` в venv, `python -m playwright install chromium` (только chromium).
2. Поднять приложение из worktree: `streamlit run app\ThermoGar_app.py --server.headless true --server.port 8601`
   с `THERMOGAR_STATE_ROOT` = временная папка (чистый профиль, чтобы в библиотеке/истории не было чужих записей)
   и `PYTHONHASHSEED=0`. Окно браузера 1440×900, светлая тема, масштаб 100 %.
3. Скрипт `tools\make_guide_screens.py`: для каждого сценария — последовательность действий Playwright
   (клик по вкладке, ввод в поле по подписи, клик по кнопке, ожидание результата — по появлению таблицы/графика,
   не по таймеру), после каждого шага — скриншот всей страницы или нужной области; подсветка целевого элемента
   рисуется поверх (`page.evaluate` — рамка 3 px + кружок с номером, цвет один на всё руководство), затем убирается.
   Streamlit-виджеты искать по тексту подписи (`get_by_label`, `get_by_role("button", name=...)`, `get_by_text`), не по CSS-классам.
   Скрипт должен перезапускаться и давать те же кадры; имена файлов — `docs\guide\img\<вкладка>-<NN>.png`.
4. Скриншоты сжать (PNG, ширина ≤ 1440, без лишнего пустого низа страницы; `Pillow` есть в venv).

## Сценарии (составы и параметры — из `tools\backend_reference.md`, быстрые, ≤ 1 мин каждый)
| Вкладка | Сценарий |
|---|---|
| Первый запуск | ярлык → браузер → выбор базы «Стали», основа FE, масс.%, состав `C=0.2, CR=11.5, NI=0.7`, 700 °C |
| Расчёты | равновесие в точке (Fe) → таблица фаз; затем T-скан 5 точек 500–900 °C → график → кнопка Excel |
| Диаграммы | бинарная Ni–Al (база Ni): выбор элементов, диапазон, «Построить» → диаграмма → PNG |
| Затвердевание | Al–4Cu–1Mg (база Al): Scheil → ликвидус/солидус, кривая доли твёрдого → Excel |
| Энергии | Ni–15Al: движущая сила FCC_A1 → GAMMA_PRIME при 700 °C |
| Свойства | Fe: плотность в точке; Ni: VRH по фазам (таблица модулей заполнена примером) |
| Кинетика | Ni: KWN γ′ короткая выдержка → доля/размер; диффузия одной фазы Ni, дефолты |
| Проекты и данные | сохранить состав в библиотеку → загрузить обратно; batch: скачать шаблон, загрузить 3 состава, расчёт; сохранить проект |
Дополнительно один кадр: переключатель «Быстрый набор / Все фазы» в «Управление фазами» и строка «Набор фаз» в результате;
один кадр: сайдбар «Параллельный расчёт: авто (N воркеров)».
