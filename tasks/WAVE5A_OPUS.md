# Задача 5A — наборы фаз по умолчанию («быстрый набор» / «все фазы»)

Прочитай `tasks\WAVE5_COMMON.md`, `tools\backend_reference.md`, `tools\ui_matrix_F.md`.

## Идея
`filter_phases` оставляет все фазы, чьи элементы есть в составе: Al–Cu–Mg → 64 кандидата, из которых в реальных
расчётах участвуют ~10–15. Стоимость каждого равновесия ~линейна по числу фаз, диаграммы — сотни равновесий.
Вводим для каждой базы **«быстрый набор»** фаз (обычные для практики) и режим **«все фазы»** (текущее поведение).
По умолчанию: одиночное равновесие и энергии — все фазы (это секунды); сканы, диаграммы, карта, затвердевание —
быстрый набор с явной пометкой в результате и в Excel. Пользователь переключает одной кнопкой в редакторе фаз;
выбор запоминается на сессию и на базу.

## Шаги
1. `configs\phase_presets.json`: `{ "ni": [...], "al": [...], "fe": [...] }` — имена фаз ровно как в TDB.
   Стартовые списки (проверить `db.phases`, убрать несуществующие, добавить очевидные пропуски):
   - ni: LIQUID, FCC_A1, GAMMA_PRIME (L1₂ Ni₃Al — найти точное имя в mc_ni), BCC_A2, SIGMA, MU, LAVES (C14), M23C6, M6C,
     MC (TiC/NbC — имя в базе), ETA (Ni₃Ti), DELTA (Ni₃Nb), GAMMA_DOUBLE_PRIME (если есть), HCP_A3, CR3SI при наличии.
   - al: LIQUID, FCC_A1, THETA_AL2CU, S_PHASE (Al₂CuMg), MG2SI, BETA_ALMG/ALMG_BETA, AL3ZR/AL3SC (L1₂), AL6MN, AL13FE4,
     AL7CU2FE, Q_PHASE, T_PHASE (AlCuMgZn), ETA_MGZN2, DIAMOND_A4 (Si), AL3TI при наличии.
   - fe: LIQUID, BCC_A2, FCC_A1, HCP_A3, CEMENTITE, M23C6, M7C3, M6C, M3C2, MC/ M(C,N) (TiC, VC, NbC — имена в базе),
     M2C, SIGMA, LAVES (C14), MU, CHI, GRAPHITE, AL_N/ TIN при наличии, FE4N. C15_LAVES — никогда.
   Для каждой базы прогнать равновесие/скан по 3 эталонным составам в режимах «все» и «быстрый»: список стабильных
   фаз должен совпасть. Если в режиме «все» стабильна фаза не из набора — добавить её в набор. Задокументировать в
   `tools\test_phase_presets.py` как тест (сравнение стабильных фаз «все» vs «быстрый» на эталонных точках).
2. `thermogar_release_policy.py`: загрузчик пресетов (`load_phase_presets(project_root)`), `PHASE_MODE_FAST/ALL`.
   Таблицу `FEATURES` не трогать (её правит 5C).
3. `ThermoGar_app.py`: в `compatible_phases_for_components` добавить параметр `phase_mode`; в `phase_selection_editor` —
   переключатель «Быстрый набор (N фаз) / Все фазы базы (M фаз)» с подписью «быстрый набор — обычные для практики фазы;
   если сомневаетесь, проверьте результат в режиме "все фазы"». Дефолт по разделам как в идее. Ручной выбор фаз
   поверх любого режима сохраняется. Фильтр C15 применяется в обоих режимах (после пресета).
4. В результатах и Excel — строка «Набор фаз: быстрый (N) / все (M)».
5. Замеры «было → стало» на диаграммах и сканах трёх баз (те же параметры, что в `ui_matrix_F.md`):
   бинарная, изоплета, тройная, карта, Scheil. Ожидание: Al в 3–5 раз, Fe в 1,5–2, Ni ~1,2.
6. Тесты: `test_phase_presets.py`; `test_ui_f.py -m "not slow"` зелёный; `test_backend_calculations -m "not slow"`
   зелёный (он использует полный набор — не должен измениться).
Отчёт: замеры, финальные списки пресетов с обоснованием добавлений, что изменилось в UI.
