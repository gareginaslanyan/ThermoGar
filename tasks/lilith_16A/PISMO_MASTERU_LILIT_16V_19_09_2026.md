## 1. Что было не так в 0.4.2 (для честности)

1. Плотность чистого элемента в правиле смеси бралась из первой найденной структуры базы
   physical_data 1.03, то есть из ГЦК: железо 8140 вместо 7876 кг/м³ (ОЦК), кремний 3053 вместо
   2329 (алмаз); так же Co, Ti, Nb, V. Отсюда +2,4 % у Al-сплавов и +2,6…+3,7 % у сталей там,
   где работало правило смеси.
2. Фаза `SI_DIAMOND_A4` базы mc_al не была привязана к модели `DIAMOND_A4` физической базы.
3. Вкладки плотности отказывали при 20 °C с внутренней ошибкой: физическая база задаёт
   плотность с 298,15 K. Теперь отказ текстом; числа ниже — при 25 °C, сдвиг 20→25 °C по
   наклону самой базы 0,02–0,03 %.

В 0.4.3 плотность элемента берётся по его эталонной фазе из записи `ELEMENT` термодинамической
базы (Fe — ОЦК, Si — алмаз, Ti/Co — ГПУ и т. д.); `SI_DIAMOND_A4` считается моделью `DIAMOND_A4`.

## 2. 16-В — плотность против ваших датащитов и измерений, 25 °C

Считали 7 марок из 11 (Copper, CuCrZr — нет Cu-базы; Ti6Al4V — нет Ti-базы; IN738 — в mc_ni нет
Ta, 1,75 % Ta без замены не считается). Составы — `marki_16A.csv`, как в 16-А. Четыре варианта:

* **A** — штатный путь вкладки «Плотность»: равновесие при 25 °C, быстрый набор фаз, плотность
  каждой фазы по своей модели физической базы, у фаз без модели — правило смеси;
* **B** — то же, полный набор (умолчание вкладки);
* **C** — «как напечатано»: весь состав в одной матричной фазе (ГЦК для Al, Ni, 316L; ОЦК для
  18Ni300 и 17-4 PH — мартенсит приближён ферритом);
* **D** — правило смеси по элементам, без равновесия.

Отклонение расчёта от датащита, %, 0.4.2 → 0.4.3:

| марка | датащит, г/см³ | A | B | C | D | в 1 % (0.4.3) |
|---|---|---|---|---|---|---|
| RS320 (измерение РУСАЛ) | 2,659 | +2,40 → **+0,18** | +2,40 → +0,18 | −5,11 | +2,40 → +0,18 | A, B, D |
| AlSi10Mg | 2,67 | +2,38 → **−0,40** | +2,38 → −0,40 | −6,70 | +2,38 → −0,40 | A, B, D |
| IN718 | 8,19 | +0,56 → **+0,35** | +0,62 → +0,43 | +0,48 | +0,46 → −0,57 | все |
| 17-4 PH | 7,75 | +0,24 → **−0,20** | +2,60 → −0,20 | +0,03 | +2,60 → −0,24 | все |
| 18Ni300 | 8,1 | — | — | +1,17 | +3,65 → +0,70 | D |
| 316L | 7,9 | — | — | +1,87 | — | нет |
| VJ159 (паспорт ВИАМ) | 8,23 | −1,44 → −1,86 | −1,44 → −1,85 | −1,45 | −1,45 → −1,90 | нет |

Что за «—». У 316L и 18Ni300 в равновесии при 25 °C есть фазы, у которых в физической базе нет
модели и не покрыты эндмемберы (`BCC_DISL`, `LAVES_PHASE`), а у азота нет плотности элемента —
приложение честно не даёт числа сплава. Это ограничение физической базы, записано у нас как
недостающие источники (S-7).

Что видно:

* **Al-сплавы** — теперь в 0,2–0,4 % от датащита и измерения, во всех вариантах с равновесием.
  Вариант C для Al бессмыслен (кремний в ГЦК-растворе — −5…−7 %), это ожидаемо.
* **IN718 и 17-4 PH** — все варианты в 1 %.
* **Стали при 25 °C в равновесии — не аустенит.** У 316L равновесие ферритное с σ-фазой, у
  17-4 PH — ОЦК с G-фазой; поэтому для сталей и никелевых сплавов ближе к датащиту вариант C
  «как напечатано» (316L +1,87 %, 18Ni300 +1,17 %). Для вашего покрытия ≥ 99 % это довод
  считать плотность по матричной фазе с полным составом, а не по равновесию при комнатной
  температуре.
* **VJ159 −1,45…−1,9 %** — единственная марка, где ни один вариант не попал в 1 %. Вариант C
  (чистая ГЦК, прямая модель базы, никакого правила смеси) даёт −1,45 % — промах сидит в
  самой модели ГЦК на этом составе; марка вне шапки mc_ni по Cr/Mo. Не доказано дальше.
* Правило смеси — оценка: у IN718 оно ушло с +0,46 на −0,57 % (железо 18 % теперь ОЦК). Так и
  записано в наших пределах применимости: ±1 % в обе стороны для фаз без модели.
