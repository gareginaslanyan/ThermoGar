## Целевой workflow кинетики после NE-03/NE-04

Сейчас кнопка расчёта отключена. Последовательность ниже документирует
будущий проверяемый workflow и не является инструкцией выполнить расчёт на
NE-02.

1. База: **Никелевые сплавы**.
2. Откройте **Кинетика → Выделения**.
3. Набор исходных параметров: **Учебный Ni–9,8Al–8,3Cr / γ′**.
4. Матрица: `FCC_A1`.
5. Фаза-выделение: `GAMMA_PRIME`.
6. Температура: `800 °C`.
7. Для быстрого теста поставьте `1 ч` и `40` классов размеров.
8. После прохождения gates станет доступна кнопка **Рассчитать кинетику
   выделений**.

Учебный набор проверяет работу программы. Для реального материала параметры
KWN нужно обосновывать открытой литературой или явно объявленным
исследовательским сценарием; это не квалификация материала.

## Обновление

Не заменяйте целиком папку ThermoGar или `databases`.
Релизного установщика пока нет: он появится только после NE-08. Текущую
development-сборку запускайте из существующего окружения и не копируйте поверх
рабочего каталога вручную.


## Fe-профили — только диагностика

Исторически использовалась `mc_fe 2.062 + TG-FE-2062-C15-001`. Конвертер
сохраняет исходную команду `G(C15_LAVES,FE,NI:MN,SI;0)=-9e6` как комментарий,
не придумывает замену и пишет JSON-паспорт. Непатченная копия нужна только для
диагностики. Обе копии исключены из расчётной поверхности SWR. Диагностическая
проверка:

```bash
./.venv-mac/bin/python tools/thermogar_fe_database_test.py --structural-only
./.venv-mac/bin/python tools/thermogar_fe_database_test.py
```

## Целевой workflow упругих свойств после NE-03/NE-04

Обе расчётные кнопки сейчас отключены.

1. Выберите материал и состав.
2. Откройте `Свойства → Упругие свойства`.
3. После разблокировки нажмите `Подготовить равновесные фазы`.
4. Заполните `E`, `ν`, происхождение и источник для всех фаз.
5. После разблокировки нажмите `Рассчитать Voigt–Reuss–Hill`.

Без свойств всех фаз ThermoGar честно откажется от итоговой гомогенизации.

## Вклады упрочнения

Откройте `Свойства → Вклады упрочнения`. Включите только механизмы, для
которых известны исходные данные. По умолчанию вклады не складываются.
Расчётная кнопка заморожена до NE-03/NE-04. После разблокировки учебный пример
будет демонстрировать формулы, но не прогнозировать марку стали.
