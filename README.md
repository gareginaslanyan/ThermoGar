# ThermoGar 0.3.0

ThermoGar — локальное настольное приложение для термодинамических
CALPHAD-расчётов сплавов. Работает без интернета, считает на открытых базах
MatCalc и показывает результат в браузере: таблицы фаз и их составов,
диаграммы состояния, кривые затвердевания, энергии, физические свойства
и кинетику.

> **Исследовательское программное обеспечение.** Экспериментальная валидация
> не проводилась: числа получены из выбранной термодинамической модели и не
> заменяют аттестацию материала. Стальная база поставляется как патч
> `TG-FE-2062-C15-001`, в котором фаза `C15_LAVES` исключена из расчёта.
> Проверяйте результаты независимо, прежде чем принимать по ним решения.

## Что считает

Семь рабочих разделов, каждый доступен для всех трёх баз:

| Раздел | Что даёт |
|---|---|
| Расчёты | равновесие при одной температуре, сканы по температуре и по составу |
| Диаграммы | бинарная T–X, многокомпонентное сечение, тройная при T = const, карта доли фазы |
| Затвердевание | равновесное охлаждение и Scheil–Gulliver |
| Энергии | кривые энергии Гиббса фаз, движущая сила выделения, температура T₀ |
| Свойства | плотность и объёмные доли, упругие свойства по Voigt–Reuss–Hill, вклады упрочнения |
| Кинетика | одномерная диффузия, многофазная гомогенизация, кинетика выделений KWN |
| Проекты и данные | библиотека составов, пакетный расчёт, проекты, история, паспорт базы, справочник фаз |

Любой результат выгружается в Excel, CSV и PNG.

## Базы данных

| База | Файл | Версия |
|---|---|---|
| Никелевые сплавы | `databases/converted/mc_ni_v2036_with_mobility.garcalc.tdb` | mc_ni 2.036 от 20.08.2024 |
| Алюминиевые сплавы | `databases/converted/al/mc_al_v2037_with_mobility.thermogar.tdb` | mc_al 2.037 от 03.10.2023 |
| Стали и Fe-сплавы | `databases/converted/fe/mc_fe_v2062_with_mobility.thermogar.tdb` | mc_fe 2.062 от 08.11.2024 + патч `TG-FE-2062-C15-001` |

Это свободно распространяемые открытые базы MatCalc, оценённые в Институте
материаловедения и технологий TU Wien (E. Povoden-Karadeniz, A. Jacob), для
некоммерческого исследовательского и учебного применения. В поставку входят
конвертированные копии: значения параметров не менялись, приведён только
синтаксис под pycalphad. Лицензионные заголовки исходных выпусков сохранены
дословно внутри каждого `.tdb` — именно они являются определяющими условиями.
О коммерческом использовании нужно договариваться с проектом MatCalc.
Полный перечень лицензий поставки — `THIRD_PARTY_NOTICES.txt`.

Физические данные для расчёта плотности —
`databases/physical/original/physical_data_v103.pdb`, версия 1.03 от
19.06.2009; описание и ограничения — `PHYSICAL_DATA_README.md`, список
ссылок — `SOURCES.txt`.

### Патч стальной базы

В исходной `mc_fe_v2.062` активен параметр
`G(C15_LAVES,FE,NI:MN,SI;0) 273.00 -9e6; 6000.00 N`. Из-за него для части
легированных сталей несколько процентов `C15_LAVES` сохраняются вплоть до
2000 K и состояние полного расплава не достигается. В поставляемой копии
эта одна команда отключена и сохранена дословно как комментарий; фаза
`C15_LAVES` и остальные 18 её G-параметров не тронуты, `LAVES_PHASE` не
изменена. ThermoGar дополнительно исключает `C15_LAVES` из всех списков фаз
стальной базы: её нельзя выбрать вручную и она не попадёт в расчёт через файл
пакетного расчёта. Исходная и патченная копии, паспорт патча и контрольные
суммы лежат в `databases/`; ответ разработчиков MatCalc на момент выпуска
не получен.

## Установка и запуск

**Установщик.** `ThermoGar-0.3.0-win64.exe` ставит программу вместе с
собственным Python 3.11.9 и всеми базами; отдельно устанавливать Python не
нужно, интернет при работе не требуется. Запуск — ярлык **ThermoGar** в меню
«Пуск». Пользовательские данные лежат вне папки установки и переустановку
переживают.

**Из папки с исходниками.** Нужно окружение `.venv-windows` в корне проекта:

```bat
RUN_THERMOGAR_WINDOWS.cmd
```

Скрипт запускает `python -m streamlit run app\ThermoGar_app.py`; приложение
открывается на `http://localhost:8501`, остановка — `Ctrl+C` в консоли.

## Где хранятся данные пользователя

`%LOCALAPPDATA%\ThermoGar` (переопределяется переменной окружения
`THERMOGAR_STATE_ROOT`). Там лежат библиотека составов, проекты, история
расчётов, локальная библиотека упругих свойств фаз и технические журналы
ошибок. Папка программы во время работы не изменяется — поэтому ThermoGar
можно ставить в `Program Files`. Подробности — `USER_DATA_README.txt`.

## Тесты

Быстрая проверка установки — вкладка **Проекты и данные → Проверка
установки**: она сверяет базы и прогоняет три контрольных расчёта.

Из командной строки:

```bat
RUN_TESTS_WINDOWS.cmd
```

Полный набор через pytest (интерпретатор — из `.venv-windows`):

```bat
.venv-windows\Scripts\python.exe -X utf8 -B -m pytest tools -q -m "not slow"
```

Маркером `slow` отмечены расчёты диаграмм: они идут десятки минут и
запускаются отдельно ключом `-m slow`.

## Обновление

Ставьте новую версию поверх старой — установщик заменяет только программу.
При ручном обновлении из архива **не заменяйте папку целиком**: скопируйте
`app/`, `tools/`, `scripts/` и файлы в корне, а `databases/` оставьте на
месте. Пользовательские данные в `%LOCALAPPDATA%\ThermoGar` не затрагиваются
ни при каком способе обновления.

## Ограничения

- Кинетика: одна пространственная координата, постоянная температура, не
  более четырёх элементов одновременно; в KWN — одна матрица и одна
  сферическая фаза-выделение, параметры зарождения задаёт пользователь.
- Упругие свойства: `E` и `ν` каждой фазы вводит пользователь с указанием
  источника; Voigt и Reuss — идеализированные границы, Hill — их среднее.
  Текстура, пористость и морфология не учитываются.
- Вклады упрочнения считаются по явно введённым коэффициентам и по умолчанию
  не суммируются; итог не является пределом текучести или твёрдостью.
- Плотность выводится только при покрытии всех равновесных фаз данными PDB;
  для Al–Cu–Mg покрытие 98,9 % (нет модели для `THETA_AL2CU`), поэтому
  плотность сплава не рассчитывается.
- Диаграммы на алюминиевой базе самые дорогие: в ней 64 активные фазы против
  34 у стальной и 15 у никелевой.
